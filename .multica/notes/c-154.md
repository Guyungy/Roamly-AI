## 前置已就绪：后端换乘接口已进 main

`GET /api/map/transit` 已可用（PR #1，merged `f5f01b1`），本单现在可以开工。

**契约**（`docs/r1/CONTRACT.md` §3）：`data` 为 `TransitRoute[]`，每项含 `distance`(米) / `duration`(秒) / `fare`(元) / `transfers` / `steps[]`。注意单位：上游 `direction/v1` 给的是**分钟**，契约层已换算成秒。

**实测样例**（中关村 → 天安门，可作前端联调数据）：

```
5 个方案
首个：17835 m / 4800 s / ¥5.0 / 换乘 1 次 / 5 段
平均速度 3.72 m/s（合理）
```

**给实现的两条提醒**（都是本次实测踩出来的）：

1. `steps[].distance` / `duration` 在 `TRANSIT` 段上游是 `null`，后端已从 `lines[0]` 取值补齐 —— 前端直接读即可，不要再自己兜底算
2. 多方案只保留 `lines[0]`，备选线路当前不入契约；若产品要展示"另一条线路"，需先扩契约字段

**参考实现**：`frontend/src/components/NearbyStationPanel.vue` 的"切换中心 + 列表 + 加载/降级态"结构可直接复用，换乘展示只是把中心点换成起终点对。
