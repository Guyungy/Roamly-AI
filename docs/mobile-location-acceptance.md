## 正常流程

| 编号 | 步骤 | 验收标准 |
| --- | --- | --- |
| N01 | 手机直接打开正式地址，进入附近推荐页面 | 无证书警告；定位入口可见、可操作 |
| N02 | 重置站点定位权限，点击“当前位置”，允许授权 | 有定位中状态；建议授权后 15 秒内取得结果，无无限加载；授权弹窗停留时间不计入 |
| N03 | 与手机地图当前位置或公共地标核对 | 建议室外偏差不超过 200 米；精度不足时明确提示，不宣称精准定位。无法观察位置时由研发提供证据，不能只凭城市正确判定 |
| N04 | 核对定位后的城市 | 与实际城市一致；直辖市及区县展示合理，无残留异地城市 |
| N05 | 选择兴趣和时长，获取附近推荐，抽查前 3 条 | 地点真实存在，围绕当前位置；若声明推荐半径，结果符合该范围；距离与地图无明显异常，比较时区分直线距离和路线距离 |
| N06 | 打开推荐详情及地图入口（如有） | 名称、地址、地图落点一致，详情可打开 |
| N07 | 移动至少 500 米，等待超过 1 分钟，再次定位并刷新推荐 | 位置更新，推荐基于新位置；推荐列表不必变化，但不得继续使用旧坐标 |
| N08 | 分别使用 Wi-Fi、移动网络重复 N02–N06 | 均能完成定位、城市识别和推荐，无持续加载或接口错误 |

## 异常及恢复

| 编号 | 步骤 | 验收标准 |
| --- | --- | --- |
| E01 | 重置权限后点击定位，拒绝授权 | 说明权限被拒，结束加载，提供权限指引或手动选位置入口 |
| E02 | 在系统／浏览器设置恢复授权，返回重试，必要时刷新 | 无需清除全部浏览器数据即可恢复正常流程 |
| E03 | 关闭系统定位后再次定位 | 明确失败提示，结束加载，可重试或手动选择 |
| E04 | 断网后分别尝试定位、城市识别和推荐，再联网重试 | 各失败环节有明确提示，恢复后可重试；缓存结果不冒充本次成功。断网不一定导致设备定位失败，按各环节实际结果记录 |
| E05 | 先选择外地城市，再获取当前位置和附近推荐 | 城市及推荐切换到当前位置，不混用手动城市与当前坐标 |
| E06 | 在确实无推荐区域验证空结果；无法找到时在独立测试环境构造 | 显示暂无结果，可调整范围或位置，不编造内容；注明验证环境，不将模拟结果算作正式环境实测 |

任何失败场景均不得用默认坐标冒充当前位置。保留上次位置或采用手动城市时，明确展示来源。

## 验收与责任

- 测试执行人：执行并记录设备及网络覆盖，提交证据。
- 研发负责人：分析缺陷、修复并提供必要的坐标来源及请求证据。
- 项目验收负责人：审核记录，确认上线结论；具体姓名待指定。
- 通过：目标手机浏览器完成“当前位置 → 正确城市 → 附近推荐”，异常提示与恢复用例通过。
- 阻断上线：主要目标浏览器无法定位、城市错误、推荐明显异地、失败冒充成功或加载无法结束。
- 待复测：修复后重测失败项，并回归完整正常流程。
- 未测项不能计为通过；验收证据齐备前保持“待手机验收”。
